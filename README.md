# 🎮 銀髮族 VR 遊戲成績管理系統

## 📌 專案介紹

本專案是一套結合 **Unity VR、C#、OOP 與 SQLite** 的銀髮族遊戲系統。

主要目的是透過簡單直覺的 VR 遊戲操作，讓長者進行認知、記憶與手眼協調相關的互動遊戲。

系統包含三款遊戲：

* 🃏 翻牌遊戲
* 🍎 水果忍者
* 🧱 方塊消除

除了遊戲本身之外，本專案也建立遊戲成績管理功能，將玩家的暱稱、遊戲類型、分數與遊玩日期儲存至 SQLite，並提供排行榜與最高分查詢。

---

# 🎯 專案目的

一般遊戲系統通常需要使用帳號與密碼登入，但考量本專案主要使用者為銀髮族，因此降低登入操作的複雜度。

使用者只需要輸入：

> **暱稱**

即可進入遊戲。

遊戲結束後，系統會自動記錄遊戲成績，讓玩家可以查看自己的最高分以及各遊戲排行榜。

---

# 🎮 系統功能

## 1. 暱稱登入

使用者不需要建立帳號或記住密碼，只需要輸入暱稱即可進入遊戲。

例如：

> 王伯伯

系統會將目前玩家資料保存，並在遊戲結束後將玩家暱稱與成績建立關聯。

---

## 2. 三款 VR 遊戲

### 🃏 翻牌遊戲

透過翻牌與配對機制進行遊戲，主要著重於記憶與認知訓練。

完成遊戲後會產生遊戲分數。

### 🍎 水果忍者

玩家使用 VR 控制器進行水果切割，根據遊戲表現產生分數。

### 🧱 方塊消除

玩家透過消除方塊進行遊戲，根據完成的遊戲內容產生最終分數。

---

# 🏆 排行榜功能

系統會依照不同遊戲分類管理成績。

玩家可以查看各遊戲的排行榜，例如：

| 排名   | 暱稱  |  分數 | 日期         |
| ---- | --- | --: | ---------- |
| 🥇 1 | 王伯伯 | 350 | 2026/08/10 |
| 🥈 2 | 李阿姨 | 300 | 2026/08/10 |
| 🥉 3 | 陳先生 | 250 | 2026/08/09 |

排行榜可以依照分數由高至低進行排序，並顯示玩家暱稱、分數與遊玩日期。

---

# 🥇 個人最高分

除了整體排行榜之外，也可以查詢特定玩家在不同遊戲中的最高分。

例如：

**王伯伯**

| 遊戲   | 最高分 |
| ---- | --: |
| 翻牌遊戲 | 220 |
| 水果忍者 | 350 |
| 方塊消除 | 180 |

讓玩家可以了解自己的遊戲紀錄。

---

# 🧪 手動輸入成績

除了正常遊戲流程之外，本專案另外設計「手動輸入成績」功能。

主要用途是：

* 開發階段測試
* 排行榜功能測試
* 快速建立測試資料
* Demo 展示
* 遊戲尚未完成時驗證資料庫功能

例如可以直接輸入：

> 玩家：測試玩家
> 遊戲：水果忍者
> 分數：999

系統會將資料寫入 SQLite，之後即可透過排行榜查詢確認資料是否正確。

這項功能也讓專案在面試展示時，可以快速展示資料新增、查詢與排行榜功能，而不需要現場完整遊玩三款遊戲。

# 🗄️ 資料庫設計

本專案使用 **SQLite** 作為遊戲成績資料庫。

主要紀錄：

| 欄位         | 說明      |
| ---------- | ------- |
| ID         | 成績資料編號  |
| PlayerName | 玩家暱稱    |
| GameType   | 遊戲類型    |
| Score      | 遊戲分數    |
| PlayTime   | 遊玩日期與時間 |

資料庫主要負責保存玩家遊戲紀錄，讓遊戲重新啟動後仍然可以查詢過去的成績。

---

# 🏗️ C# OOP 設計

本專案使用 C# Object-Oriented Programming 進行系統設計。

主要將功能區分為：

### Player

負責管理目前玩家的基本資料，例如玩家暱稱。

### ScoreRecord

代表一筆遊戲成績，包含玩家、遊戲、分數與遊玩時間等資訊。

### DatabaseManager

負責處理 SQLite 資料庫相關操作，例如：

* 新增成績
* 查詢成績
* 修改資料
* 刪除資料
* 查詢排行榜
* 查詢個人最高分

透過不同類別負責不同工作，使遊戲邏輯、玩家資料與資料庫操作不會全部混在一起。

# 🧪 測試流程

為了方便測試系統，除了正常遊戲流程之外，也提供手動輸入成績。

### 正常流程

> 登入 → 選擇遊戲 → 完成遊戲 → 產生分數 → 儲存資料 → 查詢排行榜

### 測試流程

> 輸入玩家 → 選擇遊戲 → 輸入分數 → 儲存資料 → 查詢排行榜

透過兩種流程可以分別驗證遊戲功能與資料庫功能。
